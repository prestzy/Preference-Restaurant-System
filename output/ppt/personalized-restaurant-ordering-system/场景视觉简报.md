# 场景视觉简报

## 基本判断

- 内容领域：软件工程、推荐系统、移动 Web 点餐、FYP 评估
- 使用场合：本科毕业设计答辩 + 现场系统演示
- 听众身份：2 位学术评审/导师
- 页数和时长：13 页；讲述约 13–14 分钟，演示 3–4 分钟
- 证据密度：学术高证据，重点页包含结果、解释与边界
- 汇报目标：证明问题选择合理、系统架构可维护、推荐方法可解释且原型测试结果可追溯

## 继承边界

- 从内容蓝图继承：主题、13 页页序、锁定英文标题、关键数字、来源状态
- 本文件新增：真实材料范式、视觉导演原则、视觉系统与样张校准标准
- 不重写：逐页正文、具体引用书目与逐页构图

## 正向审美北极星

- 应接近：优秀软件工程毕业答辩中的“产品系统证据 + 研究结果解释”演示，而非产品营销发布会。
- 适合内容领域：真实界面可证明系统落地，清晰的流程与数据图可解释算法。
- 适合使用场合：评审可以快速找到问题、方法、证据和限制。
- 适合听众身份：信息可核验，术语克制，图形承担解释责任。
- 美感来源：严谨层级、真实界面、数据对比、可讲的证据组织和充足留白。
- 不适用于：娱乐活动、品牌广告、儿童教育或纯商业销售演示。

## 视觉导演原则

- 观众感受：这是一个已经实现并经过系统测试的严谨 FYP 原型，而不是概念提案。
- 主要策略：系统场景页以真实产品界面为证据；方法页以流程关系为主视觉；结果页以数据对比和解释边界为主视觉。
- 视觉隐喻：仅在封面使用“从偏好信号到个性化菜单”的轻量连接感；数据页不使用隐喻。
- 信息结构：结论先行，主证据居于视觉焦点，解释与限制作为第二层。
- 审美风险：营销海报感、卡片堆砌、数据页文字过小。

## 真实材料范式

- 主要范式：开题/答辩研究问题页 + 软件架构图 + 证据解释页
- 辅助范式：产品体验展示 + 数据分析管线
- 适配理由：同时支撑“系统做出来了”和“研究问题被回答”两条证据链。
- 错误材料风险：橙色餐饮营销页、通用蓝白企业模板、无数据的科技海报。

## 视觉系统

- 整体气质：清晰、可信、现代、克制；具有移动产品温度但保持学术严肃度。
- 信息密度：封面低密度；方法与结果页中高密度。
- 页面成熟度：真实可答辩，避免模板样机。
- 字体气质：英文现代无衬线，标题稳重，数字加粗清晰，正文常规字重。
- 留白节奏：宽边距、明确层级，重点证据周围保留呼吸空间。
- 图形语言：细线系统关系、简洁数据图、实心关键数字、克制的圆角注释块。
- 图标或插图系统：仅使用少量线性功能图标；不使用卡通人物或随机贴纸。
- 图片使用方式：产品界面作为真实证据嵌入；不使用无关餐厅氛围照片。
- 色彩语义：温白底；深炭/深海军蓝承担正文与结构；珊瑚橙对应顾客界面和关键行动；青绿色用于积极证据；灰色用于限制与来源。
- 页脚来源或假设：小号灰字，左侧来源、右侧页码。

## 套系一致性锚点

- 标题层级：左上主标题，短结论作为次级层，不使用超大营销标语。
- 色彩关系：温白为主，深色文本，珊瑚橙主强调，青绿色仅标识积极结果。
- 背景质感：干净哑光浅底，极轻分区，不使用渐变光球。
- 图形风格：清晰扁平信息图、细线、真实 UI 截图、简洁数据标记。
- 组件处理：小半径圆角、细边框、克制阴影；不套娃卡片。
- 页脚规则：左下来源/假设，右下 `01 / 13` 格式页码。
- 留白与边距：统一宽边距，视觉焦点不贴边。
- 可变化：构图、主视觉位置、图表/流程类型和信息密度。

## 内容与画面比例

- 文字比例：30–40%
- 图表比例：结果页约 45–55%
- 插图或图片比例：封面约 40–50%，内容页按证据需要
- 留白比例：约 20–25%
- 场景照片最大占比：0%；本套使用产品界面而非氛围照片

## 页面类型判断

- 封面：确认项目身份、移动 Web 场景与学术气质。
- 重点内容页：保留结论、主证据、解释与边界四层。
- 数据页：图表必须有方法名、指标、数值和实验条件。
- 总结页：用贡献—边界—演示路径收束。
- 必须保持复杂度：05、06、07、09、10、11、12。
- 可降低密度：01、03、13。

## 风格确认样张选择

- 第 1 页确认：标题系统、色彩、移动产品证据与整体学术气质。
- 代表性校准页：第 11 页。
- 选择原因：该页同时要求数据图、结论、实验解释、方法标签、来源和局限，是整套最严格的信息层级测试。
- 延续方式：样张通过后，其余页面继承标题、配色、图形、页脚与留白规则，但按各页任务更换流程、架构或案例表达。

## 样张自检

- 真实答辩材料：必须。
- 有正向审美北极星：是。
- 锁定主题与数据：是。
- 焦点与层级清晰：必须。
- 不压成知识卡：必须。
- 避免模板感与风格错配：必须。
- 输出：两张独立 16:9 PNG，不做拼排。

## 已确认样张锚点

- 用户已确认第 01 页与第 11 页的视觉方向，可进入批量生成。
- 封面确立了真实移动界面、深海军蓝标题、珊瑚橙动作信号、青绿色算法信号与温白底的关系。
- 第 11 页确立了数据图、实验边界、结论条和来源页脚的证据页规则。
- 后续页面必须延续上述字体气质、配色语义、细线图形、宽边距和页脚格式；构图根据页面任务变化。
